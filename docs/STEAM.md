# Steam, consoles and mobile stores

## Steam

The game is ready for Steam except for the Steamworks binding, which must be added by the
publisher (it needs your App ID and the Steamworks SDK license).

1. Pay the Steam Direct fee and create the app to get an **App ID**.
2. Use the **GodotSteam** pre-compiled editor/templates for 4.3 (<https://godotsteam.com>), or add the GDExtension version to `addons/`.
3. The game already checks `Engine.has_singleton("Steam")` (shown in Settings). Wire achievements by calling
   `Steam.setAchievement(id)` + `Steam.storeStats()` from `EmpireSim._award()` — achievement ids are
   `first_paycheck, owner, chain, landlord, mansion, island, investor, hyper, hustler, billionaire, trillionaire, project_*`.
4. Steam lobbies/Steam Networking can replace ENet for NAT-free online play.
5. Store art: `assets/marketing/steam_header_capsule.png` (920×430) is generated by `tools/make_art.py`;
   Steam also wants a 1232×706 main capsule, 2108×460 library hero and 600×900 library capsule.

## Consoles

Godot console ports (Switch, PlayStation, Xbox) require a licensed developer account and a
third-party porting partner (W4 Games, Lone Wolf Technology, Pineapple Works). The game is
already controller-complete (every screen reachable with a gamepad) and uses the
Compatibility renderer, which simplifies porting.

## Google Play (you already have the developer account)

1. Create a real **upload keystore**: `keytool -genkeypair -v -keystore upload.keystore -alias upload -keyalg RSA -keysize 2048 -validity 10000`
2. In Godot: Project → Export → **Android AAB (Play Store)** → set keystore → Export.
3. Play Console → create app → upload the `.aab` to an internal test track first.
4. Store listing art: `app_icon_512.png`, `play_store_feature_graphic.png` (1024×500) and the screenshots in `docs/screenshots/`.
5. Target API level is 34 in the preset; bump it to whatever Play requires at upload time.

## iOS

Needs a Mac with Xcode and an Apple Developer account. Export the **iOS** preset to an Xcode
project, set your team ID, and archive.
